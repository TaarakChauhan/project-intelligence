## How to start

1. **Beginner:** Read the DOCX “How to use” beginner path → join Toastmasters or start Coursera UW specialization (audit free) → follow the 30-day plan.
2. **Intermediate:** Focus frameworks (Monroe, Duarte sparkline) + record weekly talks + TED craft talks.
3. **Advanced:** TED Masterclass / coaching; deliberate practice on storytelling and Q&A under pressure.
