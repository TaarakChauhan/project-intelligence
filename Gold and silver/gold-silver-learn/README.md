# Gold, Silver & Fiat — Learning Site

A polished multi-page static educational site about why precious metals became currency and how modern fiat systems emerged.

## Open locally

**Option A — open the file**

Open `index.html` in your browser (double-click, or File → Open).

**Option B — local server** (recommended if some browsers restrict `file://` links)

```bash
cd gold-silver-learn
python3 -m http.server
```

Then visit http://localhost:8000/

## Pages

- `index.html` — Home (hero, timeline, lesson cards)
- `why-money.html` — Why Money at All
- `why-metals.html` — Why Gold and Silver
- `coins-history.html` — Coins & History
- `gold-standard.html` — The Gold Standard
- `rise-of-fiat.html` — Rise of Fiat
- `trade-offs.html` — Metallic vs Fiat trade-offs
- `sources.html` — Sources with external links

No build step, npm, or frameworks required. Optional JS is only for the mobile nav toggle (`js/nav.js`).
