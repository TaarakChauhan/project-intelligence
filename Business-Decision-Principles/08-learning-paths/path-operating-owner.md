# Learning path: operating owner

**Purpose:** Install a weekly operating rhythm for high-quality choices.

1. Foundations 01–05: process, reversibility, models, journals, bias.
2. Owner 01–05: decision rights, allocation choices, capital, cash, dissent.
3. Use the weekly review for four weeks.
4. Add Terms 02–04 if ownership or financing affects the plan.

**Deliverable:** a decision queue, three explicit triggers, and one post-decision review.
