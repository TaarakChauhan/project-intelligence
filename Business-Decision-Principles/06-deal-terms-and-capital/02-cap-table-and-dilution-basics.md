# Cap table and dilution basics

**Purpose:** Make ownership changes visible before agreeing to financing.

**Who this is for:** Founders, investors, employees, and board members.

## Core principles
- A cap table should show legal holders, instruments, option pools, and assumptions about conversion.
- **Dilution** means an existing holder owns a smaller percentage after new shares or conversion; value can still rise if capital creates more enterprise value.
- Model pre-money/post-money, option-pool treatment, SAFEs/notes, pro-rata, and future rounds.
- Percentage ownership is not the same as control or proceeds at exit.

## How decisions actually get made
Use a version-controlled model with fully diluted definitions. Reconcile it to legal records and financing documents. Run low, base, and high next-round scenarios. Have counsel/accountants confirm the model before signing.

## Worked mini-example
Founder owns 80 of 100 fully diluted units. A new investor receives 20% post-money; founder is now 64 units of 120, or 53.3%, before any other changes. If an option-pool increase occurs pre-money, the founder’s outcome can differ. Model the actual terms.

## Common mistakes
- Mixing issued shares and fully diluted shares.
- Forgetting an option-pool refresh.
- Calculating dilution without conversion scenarios.
- Treating ownership percentage as liquidation proceeds.

## Practice exercise (10 minutes)
Create a four-row table: founder, employee pool, existing investor, new investor. Add units before and after a financing, then list the assumptions that need legal confirmation.
