| Framework | Core steps | Learn more |
|-----------|------------|------------|
| Monroe's Motivated Sequence | Attention → Need → Satisfaction → Visualization → Action | https://www.mindtools.com/at48yzw/monroes-motivated-sequence/ |
| PREP | Point → Reason → Example → Point | Practice in Q&A |
| SUCCESs | Simple, Unexpected, Concrete, Credible, Emotional, Stories | Made to Stick |

## Practice systems & feedback

- **Toastmasters:** prepared speeches, Table Topics (impromptu), structured evaluations — https://www.toastmasters.org/
- **Record yourself weekly:** phone video; score structure, fillers, pace, eye contact, gestures
- **AI coaches:** [Yoodli](https://yoodli.ai/pricing) (free tier + Pro/Advanced); [Orai](https://play.google.com/store/apps/details?id=com.orai&hl=en_US)
- **Deliberate drills:** 60-second PREP answers; random-word 1-minute talks; open with 3 hooks

## Common pitfalls & fixes

| Pitfall | Fix |
|---------|-----|
| No clear point | Write a one-sentence throughline; cut everything that doesn't serve it |
| Weak opening | Hook first 15 seconds: story, question, startling fact — never “Today I’m going to talk about…” |
| Slide reading | Slides = visual support; speak to people, not the wall |
| Filler overload | Pause instead of “um”; practice silence; record and count fillers |
| Too fast | Breathe at paragraph ends; mark pauses in notes |
| Flat delivery | Practice pitch/pace/volume on one paragraph; exaggerate then dial back |
| Ignoring audience | Eye contact zones; ask rhetorical questions; watch faces |
| Endless Q&A panic | Use PREP; buy time with “Great question…” then structure |
| Over-relying on notes | Keyword outline only; practice aloud until conversational |
| Avoiding practice | Schedule low-stakes reps (Toastmasters, video diary) |
