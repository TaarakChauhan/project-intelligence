# Speak Well

A local educational website for learning public speaking — curriculum lessons, a 30-day plan, curated resources, and blog essays.

## Open in your browser

**Easiest:** double-click `index.html` (or open it from Finder with your browser).

**Optional local server** (from this folder):

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Or:

```bash
npx serve .
```

## What’s inside

- `learn/` — lesson articles (foundations → practice)
- `plan/30-day.html` — full practice plan
- `resources/` — books, courses, talks, podcasts, tools, communities
- `blog/` — short educational essays
- `data/resources.json` — structured resource index
- `source/` — original research notes copied in for reference

Curated September 2026. External prices and pages can change.
