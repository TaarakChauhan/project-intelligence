Lesson 02

Talk structure & frameworks

~12 min read · Structure

Structure is the difference between a talk that feels intentional and one that wanders. Use these frameworks as tools — pick the one that matches your goal.

Frameworks Throughline PREP Monroe’s Motivated Sequence Duarte Sparkline SUCCESs Golden Circle STAR

Throughline

Use when: any talk longer than a minute. How: write one sentence that states the idea. Build Hook → Points → Close around it. Cut everything else.

PREP

Point → Reason → Example → Point. Ideal for Q&A, short answers, and meetings. Example: “We should ship the quiet launch first (point). It reduces risk (reason). Last quarter’s beta found 12 issues early (example). So: quiet launch, then scale (point).”

Monroe’s Motivated Sequence

A classic persuasion structure: Attention → Need → Satisfaction → Visualization → Action. Strong for pitches and calls to action. Learn more: MindTools overview.

Duarte Sparkline

Alternate what is and what could be, then land on a new bliss. Watch Nancy Duarte’s TED talk: The secret structure of great talks.

SUCCESs (Made to Stick)

Simple · Unexpected · Concrete · Credible · Emotional · Stories. Use it as a checklist to sharpen each key point.

Golden Circle

Simon Sinek’s Why → How → What. Start with purpose before features. Talk: How great leaders inspire action.

STAR stories

Situation → Task → Action → Result. Keep personal or customer stories under 90 seconds inside a larger talk.

Default outline for most talks

  1. Hook in the first 15 seconds
  2. Throughline sentence
  3. Three supporting points (each with one example)
  4. Close with a clear takeaway or action
