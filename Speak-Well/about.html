What Speak Well is

A curated educational site · September 2026

Speak Well is a local learning library for public speaking. It turns a researched set of books, courses, talks, frameworks, and practice systems into a readable educational website — closer to a calm blog/course hybrid than a random bookmark list.

How to use it

  1. Pick a path on the home page (beginner, intermediate, or advanced).
  2. Work through the Learn lessons in order.
  3. Run the 30-day plan so ideas become muscle memory.
  4. Use Resources when you want a book, course, talk, or tool.
  5. Read Blog essays for focused skills (openings, fillers, persuasion).

Editorial standard

Titles, authors, and URLs come from a curated September 2026 research pass. Where a reliable URL was unavailable, the work is still listed without a fake link. Prices change; treat cost notes as approximate.

Best progress comes from short, frequent practice with feedback — not from collecting more links.
